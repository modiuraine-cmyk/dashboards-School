## دليل مواقع مدارس النطاق الرابع بنات — واجهة تفاعلية متشعبة

ملف واحد `index.html` (HTML/CSS/JavaScript بلا أدوات بناء) يعمل كتطبيق صفحة واحدة باللغة العربية (RTL)، ويُفتح مباشرة في المتصفح أو يُنشر عبر GitHub Pages.

### مصدر البيانات
ملف «دليل مواقع المدارس — مدارس النطاق الرابع بنات» (PDF): **143 مدرسة**، منها 59 ابتدائية و37 متوسطة و28 ثانوية و19 للطفولة المبكرة.
استُخرجت أسماء المدارس وروابط «خرائط قوقل» من الملف كما هي، وكذلك ملاحظات التعليم المدمج (المدارس المستضيفة والمستضافة في المبنى نفسه).

### الهيكل الشجري للتنقل
- **الواجهة الرئيسية**: بطاقات المراحل الأربع بأعدادها، وتصنيفات سريعة.
- **المراحل الدراسية** ← قائمة المدارس (تصفية حسب النوع والاسم والرقم، ورابط الموقع لكل مدرسة) ← **بطاقة المدرسة** ← المدرسة المستضيفة أو المستضافة في المبنى نفسه.
- **حسب نوع المدرسة**: مسائية، تحفيظ القرآن الكريم، نظام المسارات، مجمع تعليمي.
- **مدارس التعليم المدمج**: 8 مبانٍ مشتركة تضم 17 مدرسة.

يتضمن بحثًا شاملًا يدعم تطبيع الحروف العربية (أ/إ/آ، ة/ه، ى/ي)، ووضعًا ليليًا، وقائمة منسدلة للجوال، وروابط مباشرة مثل `index.html#primary` أو `index.html#school-p25` أو `index.html#merged`.

### تحديث البيانات
البيانات في المصفوفة `SCHOOLS` أعلى قسم `<script>`. لكل مدرسة: `id` (حرف المرحلة + الرقم)، `n` الرقم في الدليل، `name` الاسم، `q` نص البحث في خرائط قوقل، و`host` أو `guests` لعلاقات التعليم المدمج.

# dashboards-School
 متابعة  ملفات  المشرفات (الجودة)

## بوابة مدرسة الأفق — واجهة تفاعلية متشعبة لمواقع المدارس

ملف واحد `index.html` (HTML/CSS/JavaScript بلا أي أدوات بناء) يعمل كتطبيق صفحة واحدة باللغة العربية (RTL)، ويُفتح مباشرة في المتصفح أو يُنشر عبر GitHub Pages.

### الهيكل الشجري للتنقل
- **الرئيسية**: ترحيب، أحداث قادمة، مؤشرات سريعة، مداخل البوابات، آخر الأخبار.
- **عن المدرسة**: الرؤية والرسالة · الهيكل التنظيمي (شجرة قابلة للطي) · القيادة المدرسية · الجودة والاعتماد.
- **الأقسام الأكاديمية**: المرحلة ← الصف ← الفصل ← الخطة الأسبوعية (تنقّل متدرج مع مسار تنقل Breadcrumbs).
- **البوابات**:
  - الطالب: يومي، الجدول، الدرجات، الواجبات.
  - ولي الأمر: التبديل بين الأبناء، الرسائل، الرسوم، طلب استئذان.
  - المعلم: التحضير التفاعلي، رصد الدرجات بحساب فوري، خطة الدروس.
  - الإدارة: مؤشرات الأداء ورسوم بيانية، و**متابعة ملفات المشرفات (الجودة)** مع تصفية حسب الحالة وعرض مكونات كل ملف.
- **الأخبار** (تصفية حسب التصنيف + صفحة الخبر) · **التقويم المدرسي** (شهري مع تصفية الأحداث) · **القبول والتسجيل** (معالج من 4 خطوات مع تحقق وحفظ مسودة) · **تواصل معنا**.

يتضمن بحثًا شاملًا يدعم تطبيع الحروف العربية (أ/إ/آ، ة/ه، ى/ي)، ووضعًا ليليًا، وقائمة منسدلة للجوال، وروابط مباشرة لكل قسم مثل `index.html#portals-admin`.

### التخصيص
جميع الأسماء والأرقام **بيانات تجريبية**. عدّل كائن `SCHOOL` والمصفوفات في أعلى قسم `<script>` (`STAGES`, `NEWS`, `EVENTS`, `SUPERVISORS`, ...) لتناسب مدرستك.
النماذج (التسجيل، التواصل، الاستئذان) تعمل كواجهة فقط ولا ترسل بيانات إلى أي خادم حتى تُربط بنظام المدرسة.
